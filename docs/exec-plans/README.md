# Execution Plans

Status: active  
Last updated: 2026-03-28

Execution plans are organized by current work state:

- `active/` — work currently in progress
- `pending/` — not active yet, but intentionally queued / ready for delegation
- `completed/` — finished work kept for historical reference

Directory placement is part of the documentation system. Keep it honest.

If a plan is finished, move it out of `active/`.
If a plan is not underway yet, do not leave it in `active/`.
