# Rebuild Specs

Status: historical  
Last updated: 2026-03-28

This directory contains the **historical rebuild specification** used during Ariadne's initial reconstruction.

Use it as:
- a historical design record
- a reconstruction narrative
- a source of implementation intent from that phase

Do **not** treat it as the primary source of truth for current architecture.

For current reality, read in this order:
1. `docs/ARCHITECTURE.md`
2. `docs/DESIGN.md`
3. `docs/information-architecture.md`
4. the current code

If a rebuild spec conflicts with current code or current top-level docs, the current code and current top-level docs win.
